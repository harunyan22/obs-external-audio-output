スマホ配信の構成さがし

マイクやPCの音（BGMなど）をスマホの配信アプリ（IRIAMなど）に入れる機材の組み合わせ。条件を選ぶと合う構成だけが並びます。行を押すと詳細が開き、点線の語や「?」に触れると説明が出ます。

マイク

PC

スマホ

持っている機材

名前と機能で登録すると、使える構成が緑になり、費用から除かれます。登録した機材と選んだ条件は、次に開いたときも残ります。

プリセットの機能は目安です。

Tips（必要なときだけ開く）

PCの音をスマホに送る方法

PCの音（マイク・BGM・効果音）はOBSで1つにまとめ、選んだ出力先（ヘッドホン端子、USB DAC、IFなど）へ出します。OBS標準のモニタリング機能でもできます。

自分がPCで聞く音とスマホへ送る音を分けたいときは、無料のOBSプラグイン External Audio Output を推奨します（Windows用、GitHub）。送るトラックを選べるので、「PCからはBGMだけ」の構成も作れます。

費用はマイクとPCを除いた追加購入の目安です。

持っている機材の登録のしかた
  • 1台につき1行。名前は自由（例：AG03、M2）。役割は選びません。
  • オーディオIF／ミキサー（USB）：USB端子の形、XLR入力の数、ライン入力の有無、スマホにUSBでつなげるか、PCとスマホに同時につなげるかをチェックします。
  • 足りない機材は、その行の「必要なもの」に赤字で理由が出ます。
  • 登録した機材は、次に開いたときも残ります。
PCの音を出す3つの方法
  • ソフトなし：Windowsの再生デバイスをIFにすると、PCの音はIFから出ます。マイクはIFのダイレクトモニターで混ざります。調整はできません。
  • OBS標準のモニタリング：設定 → 音声 → 詳細設定で「モニタリングデバイス」を送り先にし、ソースを「モニターと出力」にします。自分が聞く音も同じ機材からになります。
  • External Audio Output（推奨）：自分はPCのヘッドホンで聞いたまま、別の機材へ送りたいときに使います。
音が二重・繰り返しになるとき
  • OBSの出力先が、BGMを再生しているデバイスや「デスクトップ音声」が取り込むデバイスと同じだと、出した音をOBSがもう一度取り込みます。別のデバイスにします。
  • OBSでマイクを取り込みつつ、IFのダイレクトモニターやミキサーのマイク直通もオンだと、マイクが2経路で混ざります。どちらか一方にします。
  • スマホ側の機材のループバックはオフにします。オンだとスマホの音が入力へ戻ってエコーになります。
一覧に載せていない方法と、その理由
  • Bluetoothでスマホに送る：スマホのマイク入力としてつなぐと通話用の音質になり、音が大きく劣化して遅延も100ms以上出ます。
  • PCのスピーカーの音をスマホの内蔵マイクで拾う：部屋の音をそのまま拾うので、配信向きではありません。
  • 仮想オーディオケーブルだけで送る：iPhoneへ音を入れる物理的な経路が無いので、単独では成立しません。
スマホ側で気をつけること
  • 外部の音声入力をつなぐと、スマホの内蔵マイクは使われません。
  • Bluetoothイヤホンをスマホにつなぐと、入力がそのマイクに切り替わることがあります。配信中は外してください。
  • 音が割れるときはPC側の音量を下げます。それでも割れるなら抵抗入り（アッテネーター）ケーブルを使います。
  • PCとスマホを同じ電源につないで「ブーン」というノイズが出るときは、グランドループアイソレーターを試します。
番号（#111 など）の読み方

3桁の番号は構成の中身を表します。番号は条件を変えても同じなので、質問や共有に使えます。

  • 百の位＝マイク：1 USBマイク／2 XLRマイク×1／3 XLRマイク×2／4 その他（3.5mm・内蔵・ワイヤレス）
  • 十の位＝スマホに音を入れる機材と経路：1 変換アダプタ（充電可）／2 純正変換＋分岐／3 USBミキサー／4 PCとスマホ同時USB接続のIF／5 USBミキサー（マイクはじかに）／6 同時接続IF（マイクはじかに）／9 PCを使わない
  • 一の位＝PCのどこから音を出す：1 ヘッドホン端子／2 USB DAC／3 IFの出力端子／4 モニター（HDMI）／0 USBで戻す（同時接続IF）。十の位が9（PCを使わない）のときは機材：1 変換アダプタ／2 純正変換＋分岐／3 USBミキサー／7 USBマイクをスマホに直結

例：#111＝USBマイク → ヘッドホン端子 → 変換アダプタ。#251＝XLRマイク×1をUSBミキサーにじかに挿し、PCの音はヘッドホン端子から。#197＝USBマイクをスマホに直結。

「シンプル」「費用」の決め方

シンプルさは、マイク・PC・スマホ以外に置く機材の数と、落とし穴（ダイレクトモニターの二重など）の数から3段階にしています。費用は各機材の相場を足したもので、持っている機材で足りる分は除いています。

この構成で配信できた、できなかった、書いてあることが違う、といったことがあれば、noteの記事のコメントで構成の番号（#111 など）と一緒に教えてください。確認済みの更新に使います。
